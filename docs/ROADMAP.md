# Dibbly Dobs roadmap and decisions

Decisions agreed with the owner, so they survive between build phases.

## One challenge per day (required in the final version)
- Every child in a friend group gets the **same brief each day**, so the crew can compare videos for that day.
- Default limit: one challenge per day. Test briefs stay available only in test/grown-up mode.
- **Planned: "Tomorrow's pick".** Each evening, one child in the group (rotating) chooses tomorrow's concept from a few options generated by Claude. It must still use the parent keywords. Parents still preview and approve the brief before morning.

## Feel and tone (from Phase 1 testing)
- Must feel like being a creator, not homework, and not babyish.
- Creator-studio language: script, live, viewers, hype, combo, greenlit. Avoid school words (score, test, correct).
- Reading stats are hidden from the child. They go to the parent dashboard (Phase 7).
- The device voice is a placeholder. ElevenLabs replaces it from Phase 3.

## Reading check rules
- Unlock needs about 80% of the words, every keyword, **and** the last sentence read, so it never finishes mid-read.

## Phases
All seven phases are built (pending real-iPad testing):
1. Brief + read-aloud check + word help ✅
2. Claude briefs + parent keywords + phonics word bank + word moment ✅
3. Director (now a real voice call) + filming (now a live effects camera) ✅
4. Auto-edit with ffmpeg: intro, captions, effect hits, ducked music, sing-along lyrics, one remix ✅
5. Parent accounts, kid avatar + PIN login, followers, coins, shop, avatar studio, trophies, streak ✅
6. Crews (invite codes), parent approvals, premieres, sticker reactions, awards, league, Premiere Night ✅
7. Little Stars mode (Director reads first, bigger UI) + reading stats + data deletion ✅

## Next ideas
- "Tomorrow's pick": one child chooses tomorrow's theme the night before (the brief already takes a theme).
- Whisper speech recognition for reading, if Safari struggles with the kids' voices.

## Dibbly Dobs (Nov 2026)
- The app is **Dibbly Dobs**. **Star Studio** is one of five sections (with Reading, Writing, Spelling, Maths).
- **Dibbly Dobs replace coins everywhere.** Grown-ups set what each activity is worth in the portal ("Dob values"), so children get them instantly. Star Studio: once a day; the others: every time.
- Grown-ups see every Dob earned with what the child did, and can add (good), take away (naughty) or spend (shops).
- Writing goes to siblings, crew friends or a grown-up. Anything going to another family is checked by the sender's grown-up first (the only free text between children, and it is always parent-checked).
- Followers remain Star Studio's fun video score; the Dobs leaderboard covers family + crew, weekly.
