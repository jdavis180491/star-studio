# Star Studio roadmap and decisions

Decisions agreed with the owner, so they survive between build phases.

## One challenge per day (required in the final version)
- Every child in a friend group gets the **same brief each day**, so the crew can compare videos for that day.
- Default limit: one challenge per day. Test briefs stay available only in test/grown-up mode.
- **Planned: "Tomorrow's pick".** Each evening, one child in the group (rotating) chooses tomorrow's concept from a few options generated by Claude. It must still use the parent keywords. Parents still preview and approve the brief before morning.

## Feel and tone (from Phase 1 testing)
- Must feel like being a creator, not homework, and not babyish.
- Creator-studio language: script, live, viewers, hype, combo, greenlit. Avoid school words (score, test, correct).
- Reading stats are hidden from the child. They go to the parent dashboard (Phase 7).
- The device voice is a placeholder. ElevenLabs replaces it from Phase 3.

## Reading check rules
- Unlock needs about 80% of the words, every keyword, **and** the last sentence read, so it never finishes mid-read.

## Phases
1. Brief + read-aloud check + word help ✅
2. Claude brief generation + parent keywords + phonics word bank + word moment
3. Director chat (ElevenLabs voice) + filming
4. Auto-edit pipeline with ffmpeg
5. Accounts, PIN login, followers, coins, avatar studio, trophies
6. Friend groups, approvals, premieres, awards, league table, **one-per-day + tomorrow's pick**
7. Little Stars mode + parent dashboard stats
